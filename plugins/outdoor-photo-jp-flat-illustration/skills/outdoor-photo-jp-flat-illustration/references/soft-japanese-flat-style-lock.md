# 柔和平和日式扁平插画：风格锁定规则

当用户提供的目标样例呈现“温和、平和、日式平面素材感”时，本文件具有**最高视觉优先级**。它不是泛化的日漫、二次元或线稿插画，而是二维、亲切、低刺激、像生活化户外素材卡片的画面。

## 1. 必须同时出现的特征

| 维度 | 必须执行的视觉规则 |
|---|---|
| 人物比例 | 头部明显大于写实比例，身体为圆润、短而稳的块状；人物应像一个完整、亲切的简笔角色，而非被精细刻画的漫画人物。 |
| 五官 | 仅保留极少量五官：墨镜、两个点/短线眼睛、小鼻点，以及**一条可见的短弧嘴**。当嘴部未被口罩、围巾或手遮挡时，默认画一条小而友好的上扬弧嘴；用户要求中性时画平短线。不要皮肤高光、嘴唇、牙齿、睫毛、颧骨或写实脸部阴影。 |
| 轮廓 | 外轮廓使用偏深棕或柔和炭褐色的圆角粗线；内线只服务于拉链、背包边界、手臂或裤线，数量受限。不要锐利黑色漫画描边。 |
| 色块 | 以 5–8 块低至中饱和的哑光色为主；每件大物体最多一层轻微阴影。服装、背包和帐篷应是一眼可辨的平涂形状。 |
| 背景 | 用大面积分层山形、云块、树团、石块、雪块或水带表达地点。可使用少量椭圆斑点、短弧或圆角小形状提示材质，但不逐物刻画。 |
| 气质 | 温和、平静、朴素、轻松、略有手作海报感；画面留有干净空隙，主体比背景更易读。 |

## 2. 绝对排除项

以下任一特征出现，即判定为风格错误并优先重做：

| 错误类型 | 必须排除 |
|---|---|
| 泛漫画化 | 动漫人物比例、锐利发丝、赛璐璐阴影、英雄姿态、强戏剧表情、日漫速度线或复杂分镜感。 |
| 半写实化 | 真实脸部塑形、皮肤阴影、可辨齿列、鼻梁高光、真实布料、精细扣具、织物或岩石纹理。 |
| 线稿化 | 细而密的描线、黑色交叉排线、过多衣物褶皱、逐叶/逐枝/逐石的描绘。 |
| 摄影感 | 景深、镜头光晕、HDR、真实光照、反射、金属高光、复杂渐变和空气透视。 |
| 视觉噪声 | 超过 8 个主色、背景比人物更抢眼、无关道具、未经确认的文字、徽章、品牌标志、水印或签名。 |

## 3. 用户确认文字的萌化处理

默认移除文字和标志；但若用户明确要求保留短文字，或原图中存在清晰可辨且用户要求保留的文字，则将它视作保真锚点。只渲染用户确认或清楚可读的内容；无法辨识的字符、数字、单位或品牌名不得猜测补造。

| 项目 | 萌化文字规则 |
|---|---|
| 文字量 | 限 1–8 个汉字或一行很短的数字/单位；信息超过此范围时，先要求用户提供精简文案。 |
| 字形 | 使用圆润、粗厚、略不规则但仍可读的手写印刷体；可用深红、砖红、棕红或深棕色。不要书法长文、过细字体或机械 UI 字体。 |
| 版式 | 将竖排短字放在石碑、木牌、路标或帐篷等原图中的信息载体内，保持边距；可配一个小山形、太阳、星点等装饰，但不得挤压文字。 |
| 样式 | 使用米白、浅土黄或浅灰底牌，圆角边框和少量单层阴影。文字应比装饰更清楚。 |
| 验收 | 人工快速核对每一个保留字符、数字与单位是否正确；若模型生成有错别字、乱码、漏字或重复字，使用原文作一次针对性再生成。 |

## 4. 画面压缩方法

先保留人物、装备和背景中最能识别照片的 3–6 个锚点，然后把每个锚点压缩为一个圆润、清晰的色块。大背包应保留体量与位置，但只用外形、肩带、一个口袋和一个固定物说明；帐篷保留主色分区与位置；山、峡谷、树和瀑布只保留地点类别与层级。不要为了“像原图”而恢复真实纹理。

> 目标是“远看一眼就认出原照片的情境和装备，近看仍然是温和、极简、平面的日式素材插画”，而不是“把照片画成细节更少的漫画”。

## 5. 固定提示词块

将以下英文段落原样放在每次图像编辑提示词的风格段首位：

```text
Strict style lock: redraw as a peaceful, gentle Japanese flat clip-art illustration, not anime and not semi-realistic. Use a large rounded head and a compact rounded body; facial features must be minimal and graphic only. Use warm dark-brown rounded outlines, 5–8 muted matte color blocks, one very light shadow layer maximum, and large quiet background shapes. When the mouth is visible, include one small friendly curved smile. The image must feel like a simple friendly outdoor illustration card with generous clean space.
```

将以下英文段落原样放在负向约束中：

```text
Absolutely avoid anime or manga rendering, realistic facial anatomy, skin modeling, teeth, eyelashes, sharp black ink, cel shading, dense linework, detailed clothing seams, detailed buckles, photo textures, rock texture, individual leaves or branches, gradients, HDR, dramatic light, and cinematic realism.
```

## 6. 通过标准

| 检查问题 | 通过条件 |
|---|---|
| 缩小预览时，人物和装备是否仍一眼可辨？ | 是，主体以 3–6 个高辨识锚点构成，背景不抢主体。 |
| 放大后，是否仍然像简洁的平面卡通素材？ | 是，不出现真实脸部建模、密集线稿或摄影纹理。 |
| 如果去掉照片对照，是否会被误认为一般日漫角色图？ | 否，应更像平和、生活化、低细节的户外插画。 |
| 是否保留了未经确认的文字或标志？ | 否；若用户明确要求短文字，则只保留已确认的字符，并以圆润萌化字形清晰呈现。 |
