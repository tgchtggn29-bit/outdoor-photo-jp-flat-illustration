# 风格模块与质量规则

本参考文件服务于“户外照片转日式扁平插画”任务。只把用户明确提供或图片中可见的事实写入提示词；风格描述用于转换视觉语言，而非复刻任一品牌、素材库或创作者的独特标记。

## 1. 目标风格拆解

| 维度 | 应使用的描述 | 不应使用的描述 |
|---|---|---|
| 线条 | 深棕/炭黑色的圆润粗描边；线宽稳定；转折平滑；局部以内线说明口袋、拉链和褶皱。 | 极细线稿、写实素描、毛边铅笔线、机械 CAD 线。 |
| 人物 | 头部略大；脸部轮廓圆润；五官极简；手部与鞋子简化但姿势自然。 | 真实皮肤、复杂睫毛、可识别人脸精修、夸张畸形手指。 |
| 色彩 | 4–8 个主色；低至中饱和；暖棕轮廓；单色平涂为主；局部一阶阴影。 | 霓虹、HDR、镜面反射、多层空气透视或复杂渐变。 |
| 材质 | 使用少量短弧线、斑点或曲线暗示岩石、雪、叶丛与布料。 | 照片级纹理、逐像素岩壁、密集树叶、织物纤维。 |
| 光影 | 均匀柔和日光；局部阴影只用于分开衣物、背包和前后景。 | 强戏剧逆光、电影色调、硬质投影、光晕。 |
| 氛围 | 友好、安静、轻松、干净、户外探索感。 | 恐怖、末日、赛博朋克、超现实、暴力或夸张卖萌。 |

## 2. 构图与层级

保持照片的镜头距离、人物朝向和主要物体关系；不要将半身照莫名改成全身照，也不要将人物居中的照片强行改为远景。主体应保持最强对比，背景以更少纹理和更大的色块退后。

| 画面层 | 用法 | 典型元素 |
|---|---|---|
| 前景 | 可使用少量低对比的草丛、石块或栅栏边缘增加深度，但不遮挡主体。 | 叶片、石块、木栏、步道边。 |
| 中景 | 承接主体与行动场景，保留关键物件与地面关系。 | 帐篷、背包、瀑布、水面、观景台、路面。 |
| 远景 | 用大色块与简洁轮廓交代地点类别。 | 山脉、峡谷、森林、云、沙丘、雪坡。 |

## 3. 户外场景模块

每次只选择与原图一致的一个主场景模块；若场景混合，以最显眼的景观为主。

| 场景 | 可加入的正向描述 | 简化方法 |
|---|---|---|
| 高山/山谷 | 层叠山脊、深浅两级岩面、少量白色雪线、蜿蜒步道。 | 把碎石与岩壁纹理化为不规则灰褐块和几条短线。 |
| 峡谷观景台 | 木质或金属栏杆、陡峭岩壁、远处谷底的低对比植被。 | 保留栏杆横竖关系，删除牌面小字与锈蚀细节。 |
| 荒漠公路/入口 | 浅褐沙地、蓝天、远处门楼或山体、简洁道路引导线。 | 用大块暖沙色和 2–4 条道路线，不保留门楼或路牌上的文字。 |
| 雪地营地 | 白色与浅蓝雪地、深色树干、橙白帐篷、蓬松不规则雪冠。 | 雪面只保留大阴影块；树枝画成少量短杈，不逐根描绘。 |
| 林间瀑布 | 深绿树丛、蓝白瀑布竖向流线、湿润灰石、前景背包/登山杖。 | 瀑布使用 2–3 条浅蓝白色带，叶片归为团簇色块。 |
| 营地/徒步步道 | 土黄步道、灌木团块、远山、人物与背包的清晰剪影。 | 避免密集灌木和大量无关露营装备。 |

## 4. 色彩建议

以下为可参考的色感组合，不要求逐色使用。服装主色必须让位于原照片；不要因套用色板而更换外套、帽子、帐篷或背包的关键颜色。

| 场景基调 | 建议色感 | 适用情绪 |
|---|---|---|
| 山地暖日光 | 浅天空蓝、土黄、灰褐、苔绿、米白、深棕线条。 | 稳重、清爽。 |
| 红橙装备焦点 | 橘红、芥末黄、深炭灰、冷灰蓝、米白。 | 醒目但克制。 |
| 雪地 | 天空蓝、雾蓝、雪白、砖红或橙色、炭灰。 | 清冽、温暖。 |
| 林地瀑布 | 墨绿、青蓝、灰岩、奶白、深褐。 | 安静、湿润。 |
| 沙漠公路 | 浅沙、驼色、灰蓝、砖粉、炭黑。 | 开阔、干燥。 |

## 5. 可直接拼接的负向约束

根据任务选取必要项，不要把负向提示词无意义堆长。

```text
不要改变人物数量、姿势、头部遮挡关系、服装主色或关键装备；不要添加他人、动物、车辆、帐篷、旗帜或地标；不要写实摄影、3D 渲染、油画、赛博风、荧光色、强反射、复杂渐变、密集照片纹理；不要可读文字、品牌标志、水印、签名、二维码；不要畸形手指、额外手臂、漂浮背包、错误的登山杖握持或不连贯的栏杆。
```

## 6. 常见失败与一次修复语

| 失败 | 可能原因 | 一次针对性修复语 |
|---|---|---|
| 人物不像原构图 | 主体锚点不足或提示词只描述了风格。 | “恢复原照片中的人物朝向、站姿、取景距离与人物在画面中的位置；其余风格保持不变。” |
| 衣服或装备被替换 | 未明确颜色、体量和位置。 | “保留[颜色][服装]、[颜色][背包]和[物件]的相对位置；不要替换、缩小、删除或添加装备。” |
| 背景过于写实/杂乱 | 描述了场景但未规定简化级别。 | “将岩石、树叶、积雪和地面改为大面积平涂色块与稀疏短线，移除照片级细节。” |
| 线稿太细或太尖锐 | 未指定轮廓语汇。 | “统一为圆角、稳定、偏粗的深棕色描边，避免细碎尖锐线条。” |
| 添加了文字或乱码 | 图片含招牌、衣物字样或模型默认补字。 | “移除全部可读文字、商标、数字、水印和签名，保留牌子或衣物的纯色形状即可。” |
| 人物被过度美化 | 模型强化了脸部。 | “简化五官并保留帽子、墨镜或兜帽造成的遮挡关系；不补全、不精修、不改变年龄气质。” |
| 画幅裁切了主体 | 变换比例时只裁切。 | “维持原始画幅与完整主体；如需适配新比例，仅延展简化背景，不切掉头部、手脚、背包或帐篷。” |

## 7. 轻量验收清单

在交付前按“通过/不通过”检查以下事项。只要存在一个直接违背用户明确要求的关键失败，应执行上表中的一条对应修复，而非泛化重做。

| 检查项 | 通过标准 |
|---|---|
| 主体 | 人数、姿势、镜头距离和主体位置合理对应来源图。 |
| 锚点 | 至少保留用户指定或任务提取的 3 个关键锚点。 |
| 户外语境 | 仍可识别为原场景类型；主要道具与地点关系无明显错位。 |
| 风格 | 粗圆轮廓、平涂色块、有限纹理、友好日式扁平感均可见。 |
| 排除项 | 不含未授权的可读文字、商标、水印、签名或无关新增主体。 |
| 成图规格 | 画幅符合用户要求，未发生未经同意的主体裁切。 |

## 8. 权利与公开使用提醒

仅使用用户提供、授权或确认可用的图片。人物、同行者、私人地点、可识别店铺或品牌可能涉及肖像、隐私、著作权或商标问题；在公开发布或商业使用前由用户确认权限。若需要发布到小红书等平台，按适用规则考虑标注“AI 辅助创作/AI 生成”，且不要将插画伪装为真实照片或虚构户外经历。
