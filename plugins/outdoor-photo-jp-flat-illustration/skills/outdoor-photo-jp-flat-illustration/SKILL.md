# 户外照片转日式扁平插画

将人物户外照片转换为**平和、暖色、极简、低刺激的日式平面素材插画**。这不是泛化日漫或半写实线稿：人物应为大圆头、紧凑圆润身体、极简五官与稳定深棕圆角粗线；背景应由安静的大色块构成。优先保留照片中的人物动作、服装主色、关键装备和场景类型；主动简化写实纹理、背景噪点、品牌与小字。此 Skill 生成的是插画成图提示词，不执行发布、账号操作或导入登录态。

## 先判断是否适用

适用于单张或少量户外照片，主体是徒步者、露营者、登山者、滑雪者、骑行者或旅行者，且用户希望获得亲切的日式扁平插画。可处理半身、全身、人物与帐篷、观景台、山谷、瀑布、雪地、步道、营地等画面。

不适用于需要精确复刻商品标识、路牌小字、徽章、技术装备型号、写实人脸、医学/安全示意或版权角色。若用户提供的是多人合影、画面中存在关键文字、或要求保留品牌标识，先说明限制，并询问主体优先级、准确文字及商业使用需求。

> 将“像某素材站/某插画师”的笼统要求转换为可观察的视觉特征：大圆头与紧凑身体、稳定深棕圆角粗线、5–8 个哑光色块、极简五官、安静背景与大量干净留白。不要在最终生成提示词中声称与任何品牌、素材站或创作者存在关联；绝不把它误写为“动漫、漫画、二次元”风格。

## 输入与输出

| 项目 | 处理要求 |
|---|---|
| 必需输入 | 至少一张由用户提供或确认有权使用的户外照片。 |
| 可选输入 | 成图比例、人物保真重点、情绪、是否保留特定物件、输出用途、是否需要文字。 |
| 默认假设 | 单个主角；沿用原始构图和画幅；无遮挡嘴部保留一条友好的短弧嘴；默认无文字，但用户点名要保留的短文字视作保真锚点，并以圆润萌化字形呈现。保留衣物主色、头部配件、背包/登山杖/帐篷等关键装备。 |
| 交付内容 | 一段可直接用于图片编辑的中文提示词、简短保真清单和必要的风险提示。 |
| 不输出 | 身份识别结论、真实地理定位、未经用户确认的文字、虚构品牌或假冒标识。 |

## 工作流

1. **提取事实。** 仅从用户提供图片与文字中整理主体、动作、服装主色、关键装备、场景、画幅和构图。不要猜测人物身份、地点、品牌、天气时间或专业装备型号。
2. **确定保真锚点。** 选择 3–6 个最影响“这就是原照片”的元素，例如橙色冲锋衣、黑色大背包、墨镜、双手登山杖、橙白帐篷、瀑布。优先级为：主体数量与姿势、衣物主色、关键装备、画面关系、场景类别。
3. **锁定风格并选择场景模块。** 先读取 `references/soft-japanese-flat-style-lock.md`，再根据山地、峡谷观景、沙漠公路、雪地营地、林间瀑布或其他场景读取 `references/style-and-quality.md` 中的相应模块。只加入原图可见且服务于可读性的细节；若两个文件有冲突，以风格锁定规则为准。
4. **组装提示词。** 使用 `templates/prompt-brief.json` 填写字段，再运行 `scripts/build_prompt.py`；或按同一字段直接写出中文编辑提示词。必须先写“非日漫、非半写实”的固定风格锁定段，再写“仅改变视觉表达，保留锚点”。
5. **处理表情、文字与标识。** 除非嘴部被遮挡，每个主角必须保留一条小而友好的短弧嘴，或按用户要求使用中性短线。默认移除文字、品牌标志、水印与签名；但若用户明确要求保留短文字，或原图中的文字清晰可读且用户要求保留，则将文字视作保真锚点。只保留用户确认或清楚可辨的短文本；使用圆润、粗厚、略不规则但可读的萌化字形，匹配石碑、木牌、路标或帐篷等原图文字载体，并人工核对字符、数字与单位。
6. **生成与轻量验收。** 使用图片编辑/生成流程处理原图。只检查主体、锚点、画幅、插画风格及文字/标识是否符合明确要求。若出现重大偏差，进行一次针对性修正，不做无止境的主观微调。

## 提示词结构

始终以编辑指令开头，并按以下顺序组织：

```text
编辑所提供的照片：仅将视觉表现转为平和、温和的日式平面素材插画；保留[主体与姿势]、[服装主色]、[关键装备]、[场景类型]和[原始构图/画幅]。
严格风格锁定：不是日漫，不是二次元，不是半写实。人物使用大而圆的头部、紧凑圆润的身体和极简图形化五官；若嘴部未被遮挡，必须画一条小而友好的短弧嘴；使用偏深棕的圆角粗线、5–8 个低至中饱和哑光色块，每个物体至多一层极浅阴影。
背景只使用安静的大色块、少量圆角树团/石块/山形/雪块/水带与干净留白；主体轮廓最清晰。衣物与装备只保留外形、主色、位置和少量必要边界线。
不要添加照片中没有的人、动物、装备或地标；不要日漫或漫画渲染、写实脸部、皮肤建模、牙齿、睫毛、锐利黑线、赛璐璐阴影、密集线稿、细小扣具、真实材质、岩石纹理、单片树叶、复杂渐变、HDR、戏剧光影、品牌标志、水印或签名。除非用户明确指定并提供或确认短文字，否则不要可读文字；如指定，使用圆润萌化字形且逐字保持[确认文字]。输出[画幅]。
```

先读取 `references/soft-japanese-flat-style-lock.md` 的固定风格与负向约束，再使用 `references/style-and-quality.md` 获取场景词、保真锚点和失败修复语。对于结构化输入，运行：

```bash
python3 /home/ubuntu/skills/outdoor-photo-jp-flat-illustration/scripts/build_prompt.py \
  --brief /path/to/prompt-brief.json \
  --output /path/to/illustration-prompt.md
```

## 保真与视觉规则

| 层面 | 必须做到 | 默认简化 |
|---|---|---|
| 主体 | 保留人数、姿势、视角、服装主色、无遮挡时的简化短弧嘴，以及 3–6 个锚点。 | 毛孔、复杂发丝、真实皮肤纹理和小配件。 |
| 装备 | 保留背包体量、帐篷位置、登山杖等叙事性物件。 | 商标、型号、徽章、小字和精密机械结构。 |
| 场景 | 保留山地、瀑布、雪地、步道或营地的类别与大关系。 | 碎石、枝叶、岩壁、雪面等高频纹理。 |
| 风格 | 使用大圆头、紧凑身体、极简五官、深棕圆角粗线、5–8 个哑光平涂色块与单层浅阴影。 | 日漫/二次元人物、半写实五官、锐利黑线、赛璐璐阴影、密集线稿、摄影光影、油画笔触、3D 材质、漫画网点和赛博元素。 |
| 画面 | 主体占画面约 35%–70%，前中后景可区分。 | 与主题无关的装饰、过多道具和文字信息。 |

## 特殊情况

若照片中有多人，先询问每人的保留优先级；如无需澄清，保留全部人物的相对站位与主要服装色。若主体佩戴墨镜、帽子或兜帽，保留遮挡关系；只要嘴部仍可见，即使用一条小短弧嘴保留友好表情，不强行补全被遮挡的五官。若原图为竖图或横图，默认维持原比例；若用户指定新比例，要求通过延展或重构背景保全主体，除非用户明确同意裁切。

若成图用于小红书或其他公开渠道，提醒用户根据平台要求考虑标注“AI 辅助创作/AI 生成”，并确认照片版权、肖像权和可见第三方标识的使用权限。不要把 AI 生成画面包装成真实现场照片。

## 交付格式

用以下格式向用户交付，简短说明假设即可：

```markdown
**生成提示词**
[完整中文编辑提示词]

**保留锚点**
[3–6 项，均来自用户素材]

**已简化或移除**
[品牌/小字/高频纹理等]

**使用提醒**
[仅在存在文字、公开发布或权利不明确时给出]
```

在生成提示词前只询问缺失的关键信息；其他细节使用默认值。完成一个符合验收条件的版本后停止，除非用户要求继续调整。
